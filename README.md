# Retail Sales Excel Dashboard

## Project Overview
This project analyzes retail sales data using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPIs
- Data Cleaning

## Dashboard Features
- Total Net Sales
- Total Orders
- Total Quantity Sold
- Average Order Value
- Sales by Product
- Sales by City
- Sales by Category
- Sales by Payment Method
- Monthly Sales Trend
- Sales by Salesperson
- Quantity by Product

## Skills Demonstrated
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Dashboard Design
- KPI Creation
- Excel Data Analysis
